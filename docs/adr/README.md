# ADRs

Architecture Decision Records — Hongxplore's decision log. **This directory replaces any `DECISIONS.md`**; non-obvious decisions are appended here as new numbered files, never rewritten.

- Format: `NNNN-kebab-title.md` → `# ADR-NNNN: Title`, then `Status` (proposed | accepted | superseded), `Date`, `Context`, `Decision`, `Consequences`.
- Numbering: zero-padded, sequential, assigned at creation. Never renumber; supersede instead.
- The engineering skills (`domain-modeling`, `grill-with-docs`, …) read this directory — keep ADRs self-contained and current-status-first.
